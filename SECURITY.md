# Security policy

## Supported versions

Security fixes target the latest published CodexHalo release. Please update to
that release before checking whether a problem still occurs. Older releases do
not receive a separate security backport stream.

## Report a vulnerability

Use GitHub's [private vulnerability reporting](https://github.com/Mike-Animal-Counseling/CodexHalo/security/advisories/new).
Do not publish exploit details, credentials, or private session files in a public issue.

Include the affected app version, Windows version, expected security boundary,
reproduction steps using synthetic data, and the likely impact. If a screenshot
or log helps, redact account details, prompts, tokens, and personal paths first.
The maintainer will coordinate investigation and disclosure through the private report.

For ordinary bugs and feature requests, use the
[issue forms](https://github.com/Mike-Animal-Counseling/CodexHalo/issues/new/choose).
See [security and privacy](docs/security.md) for the consent model, local session
parsing and network behavior. Release privacy checks are documented in the
[release guide](docs/releasing.md).
