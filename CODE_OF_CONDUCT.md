# Code of conduct

CodexHalo welcomes contributors with different backgrounds and experience levels.

- Be respectful and constructive when discussing code, design, and bugs.
- Critique ideas and behavior without personal attacks or harassment.
- Respect privacy. Do not post someone else's account data, prompts, credentials, or identifying information.
- Keep issues and pull requests focused on the project and make room for others to participate.

Discrimination, threats, harassment, sexualized content, and deliberate exposure
of private information are not acceptable. Maintainers may edit, hide, or remove
content and restrict participation when needed to protect the project community.

Use GitHub's reporting tools for abusive public content. If an incident needs
private discussion, ask a repository maintainer for a private contact route
without posting sensitive details. Security vulnerabilities belong in the
[private reporting channel](SECURITY.md).
